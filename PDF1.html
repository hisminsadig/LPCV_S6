Ejercicios Resueltos FOR con Código

Ejercicio resuelto FOR 1 · Mostrar números del 1 al 10

Mostrar en pantalla los números del 1 al 10 usando un ciclo FOR.

Resolución

for (let i = 1; i <= 10; i++) {
                document.write(i + "<br>");
              }

Ejercicio resuelto FOR 2 · Tabla del 5

Mostrar la tabla del 5 del 1 al 10.

Resolución

for (let i = 1; i <= 10; i++) {
                document.write("5 x " + i + " = " + 5 * i + "<br>");
              }

Ejercicio resuelto FOR 3 · Suma del 1 al 100

Sumar los números del 1 al 100.

Resolución

let suma = 0;
              for (let i = 1; i <= 100; i++) {
                suma += i;
              }
              document.write("La suma es: " + suma);

FOR · Password fuerte

Construir clave: longitud + c si impar/t si par + última letra + $ si vocal/% si consonante + primeras tres letras.

Código JavaScript

let nombre = "Ana";
let ultima = nombre.at(-1).toLowerCase();
let clave =
  nombre.length +
  (nombre.length % 2 ? "c" : "t") +
  ultima +
  ("aeiou".includes(ultima) ? "$" : "%") +
  nombre.slice(0, 3);

La clave se forma exactamente concatenando esos cinco componentes.

FOR · Sumatoria de cuadrados y diagrama

Calcular 1² + 2² + 3² + … + n².

Código JavaScript

let n = 5, suma = 0;
for (let i = 1; i <= n; i++) {
  suma += i * i;
}

Pseudocódigo

Inicio
  Leer n
  suma ← 0
  Para i ← 1 hasta n
    suma ← suma + i × i
  Fin Para
  Mostrar suma
Fin

FOR · Producto de la serie

Calcular P = 1 × 1/2 × 1/3 × … × 1/n.

Código JavaScript

let n = 5, P = 1;
for (let i = 1; i <= n; i++) {
  P *= 1 / i;
}

Pseudocódigo

Inicio
  Leer n
  P ← 1
  Para i ← 1 hasta n
    P ← P × (1 / i)
  Fin Para
  Mostrar P
Fin

Diagrama de flujo

FOR · Muestra de edades del zoológico

Elefantes: 20 muestras; jirafas: 15; chimpancés: 40. Categorías: 0–1 año, más de 1 y menos de 3, y 3 años o más.

Código JavaScript

for (let i = 0; i < edades.length; i++) {
  if (edades[i] <= 1) c1++;
  else if (edades[i] < 3) c2++;
  else c3++;
}
// porcentaje = conteo / muestra * 100

Resolución: contar cada categoría recorriendo la muestra; porcentaje = conteo ÷ tamaño de muestra × 100.
